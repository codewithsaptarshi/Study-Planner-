# 📚 Study Planner — Stay Consistent & Improve Daily

An advanced, feature-packed student productivity dashboard engineered to optimize study cycles, track academic habits, and manage tasks efficiently.

🌐 **[Launch Live Web App](https://study-planner-by-saptarshi.netlify.app)**

---

## ⚡ Key Features
- 📊 **Weekly Analytics:** Live tracking of completed tasks, study streaks, and overall completion rate percentage.
- ⏱ **Focus Timer:** Built-in 25-minute countdown clock with active focus session counters.
- 🏆 **Gamified Rewards:** Performance-based reward system starting from a 🥉 Beginner badge tier.
- 📅 **Dynamic Generator:** Instantly add subjects and structure automated daily targets.

---

## 🛠️ Tech & Platform Architecture
- **Core Frontend:** HTML5, CSS3, JavaScript UI Layer
- **AI Integration:** Logical structural designs assisted by OpenAI ChatGPT
- **Cloud Hosting:** Netlify Continuous Cloud Deployment Pipelines
- **Workstation Workspace:** Maintained entirely from a mobile device (Samsung Galaxy A14 5G)
